# Soft deletion

Спосіб видалення записів таблиці бази даних при якому запис фактично не видаляється, а лише помічається як видалений.

Такі записи забезпечують цілісність даних та не відображаються у звичайному режимі на формах та у компонентах інтерфейсу.

Програмна реалізація виконується з використанням 2 додаткових атрибутів deletedDate, deletedUserId, які підключаються наслідуванням від класу BaseEntity класом сутності (Entity).
