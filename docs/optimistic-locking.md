# Optimistic locking

Спосіб виключення втрати стану запису при "одночасному" оновленні запису двома користувачами.

Див. [Optimistic concurrency control](https://en.wikipedia.org/wiki/Optimistic_concurrency_control).

Програмна реалізація виконується з використанням механізму [Versioning](versioning), атрибуту version, що проходить транзитом через API та повертається у сервіси обробки операцій зміни запису типу Update, Delete, в яких визначається відповідність версії запису. Якщо відповідність є - операція виконується, якщо версія змінилась - операція завершується виключенням (ValidationException).
