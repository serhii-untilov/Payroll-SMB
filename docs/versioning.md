# Versioning

Спосіб оновлення запису таблиці бази даних з автоматичним нарощуванням номеру версії запису.

Номер версії використовується для реалізації простого механізму [Optimistic Locking](optimistic-locking).

Програмна реалізація виконується з використанням додаткового атрибуту version, який підключається наслідуванням від класу BaseEntity класом сутності (Entity).
