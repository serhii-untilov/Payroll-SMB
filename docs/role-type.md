# Тип ролі (RoleType)

Перелік (enum) що визначає типи ролей. Використовується для визначення доступу користувачів до ресурсів системи.

Див. [Діаграма Права доступу](permissions-diagram).

Constant            |Value                |Name
--------------------|---------------------|--------------------------
SystemAdmin         |system-admin         |Адміністратор системи
CompanyAdmin        |company-admin        |Адміністратор підприємства
Accountant          |accountant           |Бухгалтер
Employee            |employee             |Працівник підприємства
Manager             |manager              |Керівник
