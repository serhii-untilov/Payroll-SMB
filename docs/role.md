# Роль користувача (Role)

Ролі використовуються для групування прав доступу користувачів до ресурсів системи.

## Структура

|Attribute|Type                 |Name    |Default   |
|---------|---------------------|--------|----------|
|name     |string(50)           |Назва   |not null  |
|type     |[RoleType](role-type)|Тип ролі|not null  |
