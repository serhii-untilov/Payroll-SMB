# CompanyRowPermission

Обмеження доступу користувачів підприємства до записів таблиць.

Див. [Діаграма Права доступу](permissions-diagram).

## Структура

|Attribute |Type                 |Name                       |Default |
|----------|---------------------|---------------------------|--------|
|companyId |[Companies](company) |Код                        |not null|
|resource  |[Resources](resource)|Назва ресурсу              |not null|
|resourceId|integer              |Id запису ресурсу (таблиці)|not null|
|action    |[Actions](action)    |Операція                   |not null|
|allowed   |boolean              |Дозволено                  |false   |

## Приклад використання:

Довідник [Норми робочого часу](work-time-norm) містить усі норми робочого часу, що використовуються на підприємствах для заповнення [Табелю робочого часу](timesheet).

Але кожне окреме підприємство потребує тільки декілька норм із довідника.
Решта записів - зайві і тільки заважають користувачу у виборі норми робочого часу у кожному окремому випадку.

Для виокремлення списку норм робочого часу, актуальних для підприємства, використовується [CompanyRowPermissions](company-row-permission).

**Примітка:** обмеження також впливає на роботу фонових процедур розрахунку та заповнення таблиць. Наприклад, заповнення таблиць Табель-Календар, Плановий табель робочого часу, Фактичний табель робочого часу буде виконуватись тільки для норм доступних підприємству.
