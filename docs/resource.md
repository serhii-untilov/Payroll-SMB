# Ресурс системи (Resource)

Перелік (enum) ресурсів (сутностей, таблиць бази даних) системи.

Актуальний перелік ресурсів знаходиться у вихідному коді програми.

Назва ресурсу - назва сутності у однині.

У структурі таблиць бази даних посилання на ресурс зберігається у атрибуті типу string(30).

**Примітка:** Назва ресурсу зазвичай вказана у заголовку на сторінці опису сутності, у круглих дужках.
